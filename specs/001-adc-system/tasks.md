**阶段 8 · 执行统一任务清单**  
**完成状态** 14 / 63。每项复制对应测试结果、业务编号及必要证据后再勾选。

一个管理网站和一个微信原生小程序经同一 Django API 读取和写入 ADC 业务事实。七个用例在同一套数据、权限及交付基线上验收。业务范围按四项业务用例、UC01–UC07、Q01–Q06 与 R01–R09。课程按两店合成数据和模拟资金验收。

## 编排与任务格式

- `Tnnn` 为开发任务。Plan 表内 `T1`–`T9` 为事务编号。`[USn]` 对应 Spec 用户故事编号。`[P]` 标记前置满足后可与文件不重叠的任务并行。
- 修改范围列出项目根目录相对路径。路径为预定落点，模型按附录 A 使用 `managed=False`，业务库沿用活动设计与验证 SQL。
- 每个故事先落实契约测试、再接入服务和客户端。开发前按预期行为断言观察失败，开发后执行对应测试。数据库关键并发使用独立 PostgreSQL 连接和真实提交。
- `AC` 是 Spec 中的验收场景；下方追踪表为正例、边界、拒绝及回滚指定测试。实施决定见[设计衔接](#设计衔接)。
