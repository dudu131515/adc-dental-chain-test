- 附录 D 提交快照曾通过 Django 75 项、网站 17 项和小程序 15 项测试。附录 E 的新证据见下表。

- 附录 D 发布时的 React 构建的 JS 和 CSS SHA-256 与云端私有 HTTPS 实际返回的文件一致。云端数据库复核 `ADC-DEMO-011` 为已确认，预约金 50.00 元，支付状态为已支付。原生模拟器归档截图来自本地合成环境，同一联验曾从员工网站与小程序打开同一个预约。云端和本地演示库分别初始化，截图日期随样例日期而异。[原生模拟器联验记录](adc-workspace.md)

- 教师主阅版使用项目目录的「双端演示补充」Word。旧提交目录中的同名最终稿及 38 表 SQL 是早期快照。当前 Word 附录 A 与 40 表 SQL 是同一设计基线。主阅版的第 4 章是分析模型，第 5 章和附录 D 是界面及授权说明。现场页面可按上述入口图核对。
- 小程序编译和本地模拟器已验证。实际界面及两端同号预约录制见[演示视频](<../../小程序备案中（网站ICP备案未完成）/ADC 双端操作演示.mp4>)。受邀真机待体验配置完成后验收。
