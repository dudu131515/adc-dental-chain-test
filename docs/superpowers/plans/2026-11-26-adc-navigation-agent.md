# ADC 首页导航与对话助手改版

## 目标

演示首页展示双店整体状态。左栏是首页和四个可展开的业务组。在业务组下点子入口即可进入对应页面。正式网站内提供有权限的专属经营助手，并给课程访客提供相同交互的合成演示。

## 交互设计

- 首页仅展示跨业务概况、各门店摘要与功能直达。预约日程、签到详情和排班操作统一由门诊运营承接。
- 左栏顺序为首页、门诊运营、患者与诊疗、收费与日结、经营与配置。四组分别包含已有的资源、临床、财务与经营配置页面。点击标题展开或收起，深链接自动展开所属组，手机支持折叠后的导航。
- 智能助手独立于普通报表。使用 ADC 的深蓝与青绿，在桌面上形成独立聊天区，在窄屏使用全宽布局。建议问题可编辑后发送，消息保留在当前对话。内容包含回答、统计出处、后续问题与明确的处理中反馈。使用文字输入。
- 实际网站将合成环境的授权经营请求交给已有 Django 服务及 DeepSeek 工具。原报表通过已签名引用打开。按当前作用域处理提交、重试和回查；不新增数据库表和外部服务。
- GitHub Pages 采用无模型凭据的合成报表适配器。公网 Django 的连通与新密钥由独立验证确认。Figma 原生稿需要连接已授权的 Figma 服务，先以交互原型落实布局。
