# ADC GitHub Pages 仪表盘演示

> 本计划按测试驱动开发和完成前验证执行。

**目标** 老师打开静态地址后，能查看实际 ADC 业务用例的可交互演示，并清楚识别数据为合成样例。

**设计** 以工作台为首页，复用 ADC 的深蓝侧栏、青绿色强调和门诊状态。切换门店和业务日期可联动概况、分时预约和日程。可打开预约详情核对过敏、履约和诊疗费用。日结台账分成功收退和在途。经营报告提供两店就诊率、未处置和净实收的可选分析，按合成事实计算并回查原始行。

**实现** 在 React/Vite 下设独立静态入口 web/demo，使用相对资源、原生表单控件和 hash 导航。生产管理网站与小程序继续使用同一 Django API。预览仅使用排定日期的合成数据，在浏览器内计算，支持托管于项目子路径。单独发布构建目录。

- [x] 实现演示入口、响应式仪表盘、可回查报表，并运行交互回归。
